# Microsoft Azure Cloud Security Labs

In diesem Bereich dokumentiere ich meine praktischen Erfahrungen mit verschiedenen Sicherheitslösungen innerhalb der Microsoft Azure Cloud.

Mein Ziel ist es, ein besseres Verständnis für die Absicherung von Cloud-Umgebungen, die Überwachung von Sicherheitsereignissen sowie die Erkennung und Analyse von Cyberangriffen zu entwickeln.

Dazu beschäftige ich mich mit verschiedenen Microsoft-Sicherheitstechnologien und dokumentiere deren Konfiguration, Funktionsweise und Einsatzmöglichkeiten anhand praktischer Labs.
